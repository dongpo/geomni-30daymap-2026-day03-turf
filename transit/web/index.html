資料從哪裡來？

TDX 於 2026/11/03 下載的 GTFS；全國檔抽取 TPE、NWT 市區公車，另用台北捷運獨立 GTFS，避免重複。公車有效期間 11/03–12/03，捷運 feed_version 為 20260906。步行路網使用 Geofabrik 的 OpenStreetMap 摘錄（2026/11/02）。畫面底圖道路來自 Overture 2026/10/21，是定位參考；實際路徑計算使用 OSM。

本版不含臺鐵、高鐵、機場捷運、環狀線或公路客運。起點範圍參考 geoBoundaries 2017 台北市界，不作法定界線用途。

如何讀取多邊形？

分析引擎計算到各格網中心的旅行時間，再合併達到時間門檻的格網。300 公尺解析度會產生階梯邊界；小範圍通行障礙不能由填色保證。目的地範圍為 121.35–121.75°E、24.90–25.25°N，範圍外不計算。

時間怎麼算？

R5 結合步行路網與 GTFS，計算步行接駁、候車、乘車與轉乘。使用所選分鐘起算的 5 分鐘出發視窗、50 百分位估計；班距型路線包含候車不確定性。公車大多只有首末站時刻，中間站由引擎插值，不能宣稱逐站精確時刻或即時路況。

網頁與運算如何分工？

MapLibre 顯示道路、起點與結果；Python API 接收查詢，R5／r5py 在後端執行分析。下載的 GTFS 與憑證不傳到瀏覽器。地圖可部署到 GitHub Pages，但公開任意點查詢需要另外運行分析服務。
